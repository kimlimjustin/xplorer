# View Modes

Xplorer offers multiple ways to display files. Switch between view modes using the view selector in the top bar, or with keyboard shortcuts.

## Grid View

Displays files as a grid of cards with icons, filenames, and basic metadata. Grid view supports four size presets:

| Size | Description |
|------|-------------|
| Small | Compact icons, more files visible |
| Medium | Default balanced layout |
| Large | Bigger thumbnails, easier to see previews |
| Extra Large | Maximum thumbnail size for visual browsing |

Change the grid size from the view options dropdown in the top bar.

## List View

A compact, single-column list showing one file per row. Each row displays the file icon, name, and minimal metadata. Best for quickly scanning directories with many files.

## Details View

A full table layout with sortable columns:

| Column | Description |
|--------|-------------|
| Name | File or folder name with icon |
| Size | Human-readable file size |
| Modified | Last modified date and time |
| Type | File extension or folder indicator |

Click any column header to sort. Click again to reverse the sort direction. Directories are shown before files by default.

## Tree View

A hierarchical folder tree that expands inline. Click the arrow next to a folder to expand it and see its children without navigating away. Useful for exploring nested directory structures at a glance.

## Column View

A macOS Finder-style multi-column navigation mode. Selecting a folder in one column opens its contents in the next column to the right. This provides a breadcrumb-like view of your navigation path and makes it easy to move between levels of the directory hierarchy.

## Gallery View

An image-focused preview grid designed for directories containing photos and media. Files are displayed as large thumbnails, and selecting an image shows a full preview in the right sidebar. Non-image files are shown with standard icons.

## Per-Folder View Preferences

Xplorer remembers which view mode you used in each folder. When you return to a folder, it restores your previous view selection automatically.

To manage this behavior, go to **Settings > Explorer**:

| Setting | Description |
|---------|-------------|
| Remember View Per Folder | Enable or disable per-folder view memory |
| Default View | The view mode used for folders without a saved preference |
