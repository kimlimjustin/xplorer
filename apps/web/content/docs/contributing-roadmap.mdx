# Feature Roadmap

Structured feature plan based on current codebase analysis. Each item includes effort (S/M/L/XL) and priority (P0-P3).

## Phase 1: Polish & Stability (v0.2.0)

### Bug Fixes & Edge Cases

| Feature | Description | Effort | Priority |
|---------|-------------|--------|----------|
| Split view persistence | Save/restore split pane layout on restart | S | P1 |
| Git status caching | Optimize expensive git status calls | S | P1 |
| Archive password handling | Consistent error handling for encrypted archives | S | P1 |
| Search index crash prevention | Graceful handling of corrupted index files | M | P1 |
| Terminal encoding fix | Handle non-UTF8 output from commands | M | P1 |
| Memory leak in AI indexing | Cancel pending indexing tasks on dir switch | M | P1 |

| Feature | Description | Effort | Priority |

| Lazy-load theme definitions | Load non-default themes on demand | S | P1 |
| Search result deduplication | Remove duplicates in hybrid search | S | P1 |
