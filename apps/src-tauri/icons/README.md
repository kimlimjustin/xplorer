# Tauri Icons

This directory should contain your application icons in the following formats:

- 32x32.png
- 128x128.png  
- 128x128@2x.png
- icon.icns (for macOS)
- icon.ico (for Windows)

You can generate these icons from a single high-resolution source image using tools like:
- `tauri icon` command
- Online icon generators
- Image editing software

For now, you can use placeholder icons or generate them from your app logo.
